
# 📂 Data Visualization with Python - Plotting Directly with Matplotlib

## 📌 Project Overview

This laboratory demonstrates how to create data visualizations directly with Matplotlib using Python. The project analyzes the Canada Immigration Dataset (1980–2013) to explore immigration trends through multiple chart types, highlighting how different visualizations can effectively communicate patterns, distributions, and relationships within the data.

## 🎯 Objectives

* Practice creating visualizations directly with Matplotlib.
* Explore immigration trends using real-world data.
* Compare different chart types for data analysis.
* Customize plots with titles, labels, legends, colors, and styles.
* Develop data storytelling skills through effective visualizations.
